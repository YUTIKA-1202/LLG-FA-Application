# LLG to Finite Automaton Converter

## Project Title

Left Linear Grammar to Finite Automaton Converter

## Student

Yutika Manekar

## Subject

Theory of Computation

## Project Description

This project is a Streamlit-based application that converts a
Left Linear Grammar (LLG) into a Finite Automaton (FA).

The application accepts grammar productions as input and generates:

- Finite Automaton states
- Alphabet
- Start state
- Final state
- Transition table
- Finite Automaton diagram
- FA description
- Excel conversion report

The application also demonstrates different valid and invalid
grammar inputs.

## Features

- Interactive grammar input
- Left Linear Grammar validation
- LLG to FA conversion
- Transition table generation
- Graphical FA visualization
- Valid and invalid test cases
- Excel report generation
- User-friendly Streamlit interface

## Technologies Used

- Python
- Streamlit
- Graphviz
